Squash Me If You Can

Welcome, crawler. The Gear Shop below is riddled with 20 intentional bugs. Find them, write them up, and report them. Every confirmed report earns a spot in the Hall of Squashers.

Enter the Gear Shop Report a bug

The hunt

  • 8 Easy Visible problems: words, numbers and buttons that look wrong.
  • 7 Medium Logic and validation: rules the site claims but does not enforce.
  • 5 Hard Edge cases, timing and accessibility. You will need patience, or a keyboard.

The bugs live on four pages: the Gear Shop (with its cart), Checkout, the Stat Calculator and Party Sign-up. Some bugs only show up when pages work together.

How to report

  1. Reproduce it twice. A bug you can't repeat is a rumor.
  2. Click Report a bug. It opens a GitHub issue form (you need a free GitHub account).
  3. Give steps, what you expected, what actually happened, and a severity.

Not bugs: the silly item descriptions, the emoji, and the fact that a cat runs this dungeon.

Hints

Stuck? Open a tier. Each hint points at one bug.

Easy hints (8)
  1. Read every word on the Gear Shop page.
  2. Not every price is a number.
  3. Keep an eye on the little number next to the cart while you shop and un-shop.
  4. What does Checkout say after you place an order?
  5. Which Checkout fields are really required?
  6. Start over on the Stat Calculator.
  7. Count your party.
  8. Try every menu link, on every page.
Medium hints (7)
  1. Filters have edges.
  2. Sort the shop, then really read the order.
  3. Quantities can be anything you type.
  4. Is one discount scroll enough?
  5. What counts as an email address?
  6. Spend every stat point. Then try one more.
  7. When can a party meet?
Hard hints (5)
  1. Cheap things add up strangely.
  2. Rearrange the shop, then go shopping.
  3. Compare the cart's total with what Checkout asks you to pay.
  4. Impatient clickers get more than they bargained for.
  5. Try Checkout with a screen reader, or by clicking on the labels.
